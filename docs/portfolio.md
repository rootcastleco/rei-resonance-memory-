# Portfolio brief — REI Resonance Memory

**Discipline:** mechanical dynamics, passive sensing, experimental design and numerical verification.

Rootcastle Engineering & Innovation investigates whether a machine can record selected vibration events without electrical power. A bank of tuned cantilevers supplies frequency-selective mechanical motion; a proposed threshold and leaky accumulator would drive a persistent flag.

The public research baseline includes an independently reproducible beam model, transient simulation, an abstract memory state machine, sensitivity analysis through parameter changes, original technical diagrams, a preliminary hardware envelope, component requirements, prior-art notes and a laboratory verification protocol. It is explicitly a pre-prototype research project. Neither hardware performance nor patent novelty has been demonstrated.

Suggested public tags: mechanical-engineering, vibration, condition-monitoring, passive-sensing, open-hardware, simulation, experimental-design.
