# Hazard and failure register

| Failure mode | Consequence | Required control / verification |
|---|---|---|
| Tip mass or mounting fastener detaches | Ejected object | Captive mass, secondary retention, guarded test, approved mount |
| Beam fractures at clamp | Loose fragment, missed event | Enclosure, certified material, fatigue and clamp inspection |
| Pawl jams or fails to advance | False negative | Independent reference measurement; never use as safety interlock |
| Mechanical chatter or shock | False positive | Adjustable stops and threshold, duration tests |
| Gravity or temperature shifts gap | Changed threshold | Orientation-specific calibration and environmental characterization |
| Accumulator damping drifts | Unreliable duration discrimination | Measure decay across temperature and wear |
| Flag resets inadvertently | Lost history | Deliberate reset mechanism and retention test |
| Base flexibility or channel coupling | Frequency shift | Fixture modal assessment and multi-channel comparison |

No safe operating limit or production readiness is established. Do not use this device to authorize continued operation of hazardous machinery. Isolate machinery before any installation or service.
